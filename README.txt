CELLARTGEN REFERENCE ADMIN PANEL
1. Backup your existing admin.html first.
2. Copy this admin.html into your Cellartgen project root (replace old admin.html only after backup).
3. Copy css/admin.css into your existing css folder.
4. Copy js/admin.js into your existing js folder.
5. Open http://localhost:5000/admin.html if your Express server serves the project files.
   If the page is not served yet, open admin.html directly in your browser for the visual preview.
Notes: This is the front-end dashboard design. MongoDB CRUD, authentication and real upload endpoints are not connected yet.
Chart.js and Google Fonts are loaded from CDN, so those parts need internet access.
